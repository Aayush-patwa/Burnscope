# Demo photos (not included)

This folder is where the "sample photo" picker in the app and a few tests look for demo burn photographs. The
photos used during development come from third-party sources and show real people, so they are **not part of
the public repository**.

To use the picker, put your own JPG files here (photos you have the right to use, ideally without identifiable
people). Without them the app works normally and the tests that need them are skipped.

For research-grade images, the public datasets used to train and evaluate the models are listed in the main
README under "Data and sources".
